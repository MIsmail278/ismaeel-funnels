Your setup

OmniRoute setup

OmniRoute is an open source gateway that runs on your computer. It gives your coding tools one local endpoint and routes their requests to the AI providers you connect. Follow these four steps on your computer.

Before you start

Claude Code, already installed.

Node.js with npm, for the install command.

A free account with at least one provider. Some need an API key, approval or a payment method. Check the free tiers guide.

Step 1: Install OmniRoute

Let Claude do it, or run the command yourself.

  1. Copy the repo link

    Open the OmniRoute repo and copy the link from the address bar.

  2. Ask Claude Code to install it

    Open Claude Code in your folder, paste the link and send this. Read what it plans to run before you approve it.

    install this repo in my folder

  3. Or install it yourself

    This is the install from OmniRoute's own quick start. On npm 11 or later, npm may block the install scripts OmniRoute needs. If you see that warning, use the allow-scripts command in the quick start.

    npm install -g omniroute

  4. Start it

    Your dashboard opens at http://localhost:20128.

    omniroute

Step 2: Connect a free provider

OmniRoute needs at least one connection before it can route anything.

  1. Open Providers

    In the dashboard, open Providers.

  2. Choose one that fits

    Pick a provider whose current terms, privacy policy and quota work for you. Providers marked tos: avoid are left out of automatic routing by default.

  3. Connect it with your own account

    Add its API key or complete its account flow.

Step 3: Point Claude Code at OmniRoute

One command writes the config.

  1. Run configure

    It shows the models available to you and writes Claude Code's config.

    omniroute configure claude

  2. Pick auto

    Choose auto to route among your eligible connections, or pick one provider and model.

  3. Restart Claude Code

    Claude Code reads these settings once at startup, so close it and open it again.

Step 4: Check that it worked

Your key is in the dashboard under Endpoints.

  1. List your models

    Replace YOUR_KEY with your OmniRoute key. You should get a list of models back.

    curl http://localhost:20128/v1/models -H "Authorization: Bearer YOUR_KEY"

  2. Launch it directly if you prefer

    This starts Claude Code against your local OmniRoute without writing a config.

    omniroute launch

Five habits

  • You are on a free model, not Claude.Answers, speed and limits depend on which provider handles the request.
  • Keep client code out of it.Free tiers can log your requests or train on them. Read each provider's privacy policy before you send it anything private.
  • The token number is an estimate.OmniRoute estimates about 1.6 billion free tokens a month across providers. You only get what the accounts you connect allow.
  • Connect more than one provider.A fresh install can have no route available, and one free tier can run out. More connections give auto somewhere to go.
  • Limits and terms still apply.OmniRoute does not change a provider's rules. Check them, because free tiers change.
