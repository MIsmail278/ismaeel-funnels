Your setup

Claude Code setup

Claude Code reads your project, edits files and runs commands from plain English. Pick a route and follow the steps on your computer.

Before you start

A paid Claude plan: Pro, Max, Ultra, Team or Enterprise. The terminal route also accepts a Claude Console account. See current plans.

A project folder to work in. Start with something small you know well.

Route A: desktop app

No terminal. Best if you have never opened one.

  1. Download the app

    Open the official download page and choose macOS or Windows.

  2. Install and sign in

    Run the installer, open Claude and sign in with your Anthropic account.

  3. Open the Code tab

    Click Code at the top of the sidebar. If you are asked to upgrade, you need a paid plan first.

  4. Choose your folder

    In the row under the prompt box, open the first control and pick the top entry under Local. Then click the folder control, choose Open folder… and select your project.

  5. Give it a job

    Type what you want in plain English, or use the three prompts below.

  6. Review the changes

    After an edit, click the +12 -1 style indicator to see what changed. In Manual mode, Claude waits for your approval on each change.

Route B: terminal

Same tool, run from the command line.

  1. Install it

    Run the line for your system. It shows no progress while it downloads.

    Windows PowerShell
    irm https://claude.ai/install.ps1 | iex
    Mac, Linux, WSL
    curl -fsSL https://claude.ai/install.sh | bash

  2. Check it worked

    Open a new terminal window and run this. It should print a version number. If claude isn't found, fix your PATH.

    claude --version

  3. Start it in your project

    Replace the path with your own folder.

    cd path/to/your/project
claude

  4. Sign in

    On first run it asks you to log in. Finish in your browser. You only do this once.

Your first three prompts

Run them in order, on either route.

  1. Have it read your project

    Check that it understands what you built.

    what does this project do?

  2. Create its instructions file

    This generates a starting CLAUDE.md from your code. Edit it down to what matters.

    /init

  3. Give it a small real task

    Keep the first change easy to check.

    Add tests for the main function

Five habits

  • Be specific."Fix the login bug where users see a blank screen after a wrong password" beats "fix the bug."
  • Let it read before it writes.On anything bigger than a small fix, ask it to analyze the code first.
  • Break big jobs into steps.Give it a numbered list instead of one giant request.
  • Use /clear between tasks.If you have corrected it twice and it's still wrong, /clear and write one better prompt.
  • Review every change.You keep what you approve. Read the diff before you ship it.
