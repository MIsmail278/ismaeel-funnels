Your setup

REA setup

REA connects your AI agent to tools that inspect native binaries, JavaScript and Electron apps, .NET assemblies and websites. Analysis runs locally. Follow the steps on your computer.

Before you start

The official repo: github.com/morluto/rea. A similar repo name does not make a download official.

Node.js with npm: 22.x (22.23.4 or later), 24.x (24.22.1 or later), or 26.12.1 and later. Get Node.js.

An agent REA supports, such as Claude Code, Codex or Cursor.

Only use REA on apps you own or are allowed to inspect.

Route A: ask Claude Code

No terminal. Claude Code runs the setup and you approve it.

  1. Open Claude Code in a safe folder

    Use a folder you trust, outside the project you plan to inspect.

  2. Paste this prompt

    It asks for a read-only plan first.

    Run npx -y rea-agents@latest setup --client claude_code --dry-run and show me the plan. If I approve it, run the same command with --yes instead of --dry-run. The official source is github.com/morluto/rea.

  3. Review and approve

    Read what it plans to change before you say yes. Setup backs up existing configuration.

  4. Restart Claude Code

    REA is available after the restart.

Route B: terminal

Use this for Codex, Cursor or more than one agent.

  1. Check Node.js

    It should print a version that meets the minimum above.

    node --version

  2. Run setup

    Run it from a trusted folder outside the project you plan to inspect.

    npx rea-agents setup

  3. Choose and approve

    Pick your agents, review the proposed changes and approve them. npm's download approval and REA's setup approval are separate.

  4. Restart your agents

    Restart each agent named in the completion message. Using Claude Desktop as an agent? Quit it fully before you approve.

Your first prompt

Replace Notes with your app and the feature you want to understand.

  1. Ask your agent

    It inspects the feature, shows the evidence, then builds a version for your project.

    Understand how search works in the Notes app, show me the evidence, and build a similar feature for my project.

Three things to know

  • Stick to official sources.Those are morluto/rea, rea.tools and the rea-agents npm package.
  • Native apps need an engine.Static JavaScript analysis needs none. Native analysis can use Hopper, Ghidra, IDA or Kuna. Setup can install Hopper if you approve it.
  • Stay within your rights.Only inspect apps you own or have permission to analyze.
